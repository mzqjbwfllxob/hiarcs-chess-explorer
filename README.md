## Overview

HIARCS Chess Explorer combines a PGN database manager with integrated HIARCS engine analysis, opening book management, and tournament tracking for players from club to GM level.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **HIARCS Chess Explorer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **PGN Database** | Import, search, and manage millions of PGN games with custom filters |
| **Engine Analysis** | Integrated HIARCS engine with configurable depth and multi-line output |
| **Opening Book** | Extensive ECO-classified opening tree with statistics and annotations |
| **Tournament Tracking** | Round-robin and Swiss pairing manager with cross-table export |
